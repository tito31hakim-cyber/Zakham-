# Zakham Perfume — زخم برفيوم

## تجربة المتجر الحالية

الصفحة الرئيسية أصبحت واجهة متجر إلكتروني كاملة مستوحاة من رحلة التسوق الحديثة: شريط إعلان، هيدر تجاري، تصنيفات، بانر رئيسي، عروض، بطاقات منتجات، فلاتر، سلة جانبية، بحث، قسم تركيب خاص، تقييمات، ونشرة بريدية.

السلة والبحث يعملان محلياً داخل المتصفح لأغراض المعاينة. زر متابعة الطلب لا ينفذ دفعاً ولا يرسل أو يحفظ بيانات. يمكن ربط الدفع، المخزون، الحسابات، ونماذج الطلب لاحقاً بعد اعتماد التكاملات.

## تعديل سريع

- **الألوان:** عدّل متغيرات `:root` في `styles.css`، خصوصاً `--gold` و`--ink` و`--pink`.
- **النصوص واللغة:** عدّل المحتوى العربي والإنجليزي داخل كائن `translations` في `script.js`.
- **المنتجات والأسعار:** عدّل مصفوفة `products` في أعلى `script.js`.
- **الصور:** استبدل مسارات `/manus-storage/...` في `index.html` و`script.js`.
- **الشعار:** `public/zakham-house-logo.jpg` هو الشعار الرسمي الأفقي لدار زخم، ويُستخدم في الهيدر والفوتر دون قص أو تشويه.

## ملفات المشروع

`index.html` للهيكل، `styles.css` للتصميم المتجاوب، و`script.js` للمنتجات والفلاتر والسلة والبحث والتبديل بين العربية والإنجليزية.

## النشر الثابت

يستخدم النشر مجلد `public/` كمخرج ثابت، ويحتوي على نسخة النشر من `index.html` و`styles.css` و`script.js` وملفات الأصول. عند تعديل ملفات الجذر، انسخها إلى `public/` قبل إنشاء نسخة نشر جديدة.
