# Zakham Perfume — زخم برفيوم

## تعديل سريع

- **الألوان:** افتح `styles.css` وعدّل المتغيرات داخل `:root`. اللون الرئيسي للهوية هو `--gold`، والخلفية `--ink`، والنص الفاتح `--cream`.
- **النصوص:** افتح `index.html` وعدّل النص العربي مباشرة. النسخة الإنجليزية محفوظة في أعلى `script.js` داخل الكائن `translations.en`، والعربية داخل `translations.ar`.
- **الصور:** استبدل مسار الصورة في `index.html` داخل `src="/manus-storage/44522_70a2e3c0.jpg"`. ارفع الصورة الجديدة إلى أصول المشروع ثم استخدم مسارها هنا.
- **الشعار:** الشعار المعتمد موجود في `logo.svg` و`public/logo.svg` داخل حاوية SVG مستطيلة تحافظ على الصورة الأصلية كما هي دون قص أو تغيير ألوان أو تشويه للنسب.
- **النماذج:** النماذج في `index.html` مرتبطة بسلوك تجريبي في `script.js`. حالياً تمنع الإرسال وتعرض رسالة توضح أن البيانات لم تُرسل أو تُحفظ. لا تُربط بخدمة حقيقية إلا بعد اعتمادك.

## الملفات الأساسية

`index.html` يحتوي على الهيكل والمحتوى، `styles.css` يحتوي على نظام التصميم والتجاوب، و`script.js` يحتوي على تبديل اللغة، القائمة المتجاوبة، ورسالة النماذج التجريبية.
